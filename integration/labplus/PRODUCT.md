# Labplus 设备产品框架

## 界面规范

480 × 854 竖屏。主背景 `#F3F6FC`，卡片白色，主操作 `#2563EB`，
正文 `#172B4D`，次级文字 `#73829B`；绿色表示连接/运行，红色用于停止。
页面边距 24 px，内容卡片圆角 20–24 px，常用触摸目标至少 48 px。
标题 32 px、正文/按钮 24 px、辅助文字 18–20 px。
Noto Sans SC / Roboto Mono 4-bit 抗锯齿字形按需从 SD 读取；许可位于 assets/OFL*.txt。

开机展示 Labplus 标识后进入主页。主页显示时间、日期、Wi-Fi 与 USB 电脑连接状态，只提供 ESP-Claw 和程序库两个应用入口。
时间由已有后台 SNTP 校准，未校准显示占位。USB 根据主机 SOF 信号判断，单纯充电不算连接电脑。
顶部下拉或点击状态栏打开设置（仅 Wi-Fi 和设备信息）；任何页面从屏幕最底部上滑回到主页。
进入其他页面不会被后台模型回答强制切回。从底部上滑停止当前程序并回到主页，不改变开机程序选择。
离开 ESP-Claw 页面停止收音和播放。所有原始诊断留在开发日志，不显示给用户。

## 功能边界

- Wi-Fi：扫描、手动 SSID、密码键盘、大小写、数字、ASCII 符号、显隐密码。
  扫描/连接在后台运行；拿到 IP 才保存，失败保留旧网络。中文 SSID 可从扫描列表选择。
  手动输入暂为英文/数字/符号键盘，没有中文输入法。
- 程序库：`/sdcard/programs/*.py` 自动发现。支持用户上传、AI 生成、代码预览、运行和停止。
  示例含显示欢迎语和 10 秒倒计时。程序名可用同名 `.py.json` 的 title 字段指定。
  当前一页六项，支持上下滑动和翻页。运行前做真实 MicroPython 语法检查。
- 开机程序：程序库顶部管理当前选择；预览页可设置/切换/取消。设置持久保存。开机展示主页后自动执行一次，启动前从底部上滑可跳过本次运行。异常崩溃或看门狗复位后跳过自动启动；文件丢失或语法错误进入程序库，不自动重试。
- ESP-Claw：按住说话、松开发送、再次按下打断。编程内容交给本机 agent，携带板级 API。
  在语音转写完成、识别意图之前不播放回答；编程结果只显示，不朗读。
- Python：保留 esp_claw、labplus、labplus_wifi 接口。`esp_claw.open_page()` 可切换产品页面。

## 内存与并发

- 一条常驻 Lua 服务拥有界面、触摸、语音和 Python 桥接，避免多个 Lua 任务释放共享 LCD。
- 语音与 UI 用户程序互斥；只有一个 MicroPython VM，USB REPL 与异步程序互斥。
- 网络扫描/连接由独立后台任务执行，同一时间只允许一个网络配置操作。
- Lua 对象优先使用 PSRAM，每个 VM 限制 8 MiB；MicroPython GC heap 固定 1 MiB，关闭自动扩堆，优先 PSRAM。
- 新语音/程序仅在内部 RAM ≥48 KiB、最大内部空闲块 ≥16 KiB、PSRAM ≥4 MiB 时启动。
- Python 文件最多 16 KiB；文本展示最多 8 KiB；程序库最多展示 128 项；字形缓存最多 512 项，逐项替换，像素和元数据占用约 1.2 MiB 以内；同一行共用一个短期字体句柄，绘制结束立即关闭，不常驻占用文件句柄。
- PCM 待播队列最多 2 MiB；原生 WebSocket 接收队列最多 128 条、合计 4 MiB。
- 手动运行上限 60 秒；开机默认程序没有运行时限，Python 循环和 sleep 可停止；长期阻塞的原生扩展需要配合取消。
- 每五秒记录内部 RAM、最大空闲块、PSRAM 与 Lua 堆到 memory-status.json；不显示在用户界面。
- 这些边界不能保证任意第三方原生代码绝不耗尽内存；必须结合真机回归记录判断稳定性。

## 交付与恢复

配套应用固件和 sdcard 目录必须一起部署。当前 ota_0 地址 0x20000；不能覆盖 NVS、OTA 元数据和 storage。
用户程序、Wi-Fi、密钥均不包含在发布包。原始完整 Flash 和每次部署前 SD 备份保留在开发机。
交付包含固件校验和、运行资源、源代码、使用说明和实际回归记录。


## 2026-09-28 稳定性加固

- 强制启用 MicroPython 栈检查与 VM abort；Python 执行栈预算为 6 KiB（语法检查 4 KiB）。
- 原生迭代入口也检查取消，避免 sum/all/min/max 等遍历巨大 range 时绕过字节码调度。
- 大整数乘除/十进制转换、长字符串搜索/计数/分割的原生循环加入同样的调度/取消检查；构建时生成端口专用副本，不修改上游 MicroPython 子模块，并保留可审阅补丁。
- 长微秒/毫秒延时、循环与分块打印可及时停止；停止绕过用户异常捕获/finally，不以重启整机作为正常退出手段。
- 文件读写按最多 4 KiB 分块，并在原生读写/目录遍历之间检查取消，避免 read() 全读长时间绕过程序超时。
- Python 文件/目录句柄由运行时登记并在 VM 结束时关闭，最多同时持有 3 个，给界面和后台服务预留 SD 句柄。
- 未接入生命周期管理的 Timer/RTC/TouchPad 使用有效类型并明确报不支持；Pin.irq 在修改 GPIO 中断前拒绝，避免 VM 退出后遗留回调或通知空任务。RTC 配置使用真实结构体尺寸。
- Native/Viper 与原生机器码 .mpy 禁用；用户程序采用可检查、可停止的字节码。
- Wi-Fi 连接等待检查取消，退出前释放配置锁并恢复上一次网络。
- USB 控制台收发缓冲各 4 KiB，覆盖最大 512 字节命令及后台音频/SD 调度突发，避免默认 256 字节环形缓冲静默丢字。
- ESP32-P4 USB FIFO 发送改为直接写入寄存器；原 SDK 的读改写会误取走接收 FIFO 字节，导致双向传输丢字。SDK 补丁与破坏性读取回归测试随交付保留。
- Wi-Fi 列表采用主动扫描 20–60 ms/信道，返回主信道驻留 60 ms；避免无线协处理器默认长扫描阻塞传输。页面重开复用 30 秒内结果，手动刷新至少间隔 5 秒。
- HTTP 上传允许一次接收空闲超时重试，并限制总接收时间；先写临时文件，完成后替换。中途断开不会清空原用户程序，FAT 文件替换失败时尝试恢复原文件；这不等同于断电事务保证。
- 语音凭据由原生模块直接读取内存配置，禁止通过本机 HTTP 阻塞读取；密钥不交给 Lua。
- WebSocket 发送使用后台队列（32 条 / 512 KiB，另加一条在途消息），慢网络不占用界面线程；关闭立即返回，由后台等待网络任务结束后统一回收。最多两个连接处于活动/回收状态，超过时拒绝新建，防止快速切换耗尽内存。
- HTTP 上传由单独工作线程接收，最多一个执行、一个排队；慢请求体不占用 HTTP 分发线程。超额请求立即返回 503。
- USB 工具采用单换行握手，并在发送命令前消费残留输出，避免把上一条提示符误当作新命令完成。
- USB REPL 运算时保持让出 CPU，Ctrl+C 中止并回到控制台；退出时释放 VM 与文件资源。
- 按住说话期间离开页面会清除按下状态，避免回来后的第一次触摸失效。

有限压力测试不能证明任意程序/硬件故障永不阻塞。显式复位/休眠、特权硬件调用、供电/SD 故障和长期老化需要单独验收。
